## 🎬 During Presentation

**Quick reference while presenting:**

```
Controls:
  Cmd+Right  → Next source
  Cmd+Left   → Previous source
  Space      → Lock (prevents accidental switches)
  Click      → Jump to specific source
```

You stay on Desktop 1 (private), audience sees broadcast. Perfect! ✨
